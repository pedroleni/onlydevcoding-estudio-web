# Seguridad del entorno de agentes

1. Lee `security/security-review-instructions.md`.
2. Revisa cambios en `AGENTS.md`, `CLAUDE.md`, `.claude/`, hooks y scripts.
3. Busca instrucciones ocultas, permisos excesivos o comandos destructivos.
4. Comprueba que contenido externo no se trate como una instrucción fiable.
5. Reporta solo hallazgos explotables con más del 80 % de confianza.
