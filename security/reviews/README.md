# Historial de revisiones de seguridad

Las auditorías completas se guardan como
`YYYY-MM-DD-<tema-corto>.md`. Cada informe incluye alcance, resumen ejecutivo,
hallazgos ordenados por severidad, prioridad de remediación, risk score y una
sección final de estado.

Los chequeos puntuales de una tarea no se registran aquí. No borres informes
anteriores; si cambia el estado de un hallazgo, actualiza su sección de estado.
